# Provenance

A text-only copy of the Impeccable skill: `SKILL.md` and `reference/` from
https://github.com/pbakaus/impeccable at commit 508d7e8 (skill version 0.1.11), Apache-2.0 (see LICENSE).

The launcher binary, `scripts/`, hooks and agents are deliberately left out, so nothing here executes.
Where a reference says to run `scripts/impeccable ...`, the launcher is unavailable and the skill's own
fallback applies: read PRODUCT.md and DESIGN.md directly. `live`, `generate`, `pin`, `doctor` and the
detector therefore do not work; `critique` and `audit` run without the deterministic scan.
